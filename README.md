# Peace And Love

> 让 Minecraft 的敌对生物放下武器，坐下来和你做生意。

厌倦了被苦力怕炸掉农场、为一颗末影珍珠追着末影人满世界跑？**Peace And Love** 把原版敌对生物变成**可以交易的中立生物**——不用拔刀，用绿宝石就能买到它们的掉落物。专为热爱种田、建筑与和平玩法的玩家设计。

这是 **Beta 早期版本（0.1.0）**，核心玩法已完整可用，平衡与细节仍在打磨。

---

## 这是什么

装上模组后，原本主动攻击你的怪物会转为**中立**：

- 🕊️ **不再主动攻击** —— 38 种原版敌对生物默认放下敌意（苦力怕、骷髅、僵尸、末影人、监守者……）。
- 💎 **右键直接交易** —— 走向一只中立的怪物，空手右键即可打开它的交易界面，用绿宝石购买掉落物。
- ⚔️ **但你打它，它照样还手** —— 中立不是无害。谁动手，怪物就记谁的仇，不会殃及旁边的队友。
- 👥 **同族会互相求援** —— 4 格内的同类会被惊动来帮忙，但示警不会无限连锁扩散。
- 🧘 **打不过就跑** —— 脱战 30 秒，或与怪物拉开 32 格距离，它就会冷静下来恢复中立。

---

## 怎么玩

1. 找到一只原本敌对、现在中立的怪物（它不会再追你）。
2. 空手**右键**它，打开原版风格的交易界面。
3. 用**绿宝石**兑换它的掉落物：末影珍珠、骨头、火药、烈焰棒……
4. **每样商品每个游戏日限购一次**，过一天自动补货，避免无限刷物破坏平衡。
5. 报价随掉落物稀有度浮动：常见掉落只要几枚绿宝石，凋灵骷髅头颅这类稀有物则贵得多（具体价格以游戏内报价为准）。

> 📌 **Boss 不可交易。** 凋灵等首领生物会被中立化、不再无端攻击玩家，但不会成为商人。**末影龙不受本模组影响**，仍是最终挑战。

---

## 管理员：让某些怪物保持敌对

不是所有怪物都得变友好。管理员可用命令精确控制哪些生物**保持原版敌对**（白名单）：

```
/pal whitelist add minecraft:pillager      # 把掠夺者移出中立化、恢复原版敌对
/pal whitelist remove minecraft:pillager   # 重新纳入中立化
```

- 默认有 **6 种生物保留原版敌意**：掠夺者、卫道士、唤魔者、恼鬼、幻翼、潜影贝。
- 改动**即时生效、无需重启**，可随时来回切换。

## 安装

| 项 | 要求 |
|---|---|
| Minecraft | **1.21.1** |
| Java | 21 |
| 加载器 | **Fabric** 或 **NeoForge** |
| 前置 | **Architectury API**（及 Fabric 端的 Fabric API） |

✨ **只需在服务端安装，原版客户端无需安装本模组即可加入并交易。** 交易使用原版村民式界面与网络协议，玩家用原版客户端连入装有本模组的服务器就能正常买卖——这非常适合和平向生存服务器。单人游戏时任一加载器正常安装即可。

---

## 它不会做什么

- **不影响第三方模组添加的生物** —— 只对原版 38 种适配过的生物生效，其它模组的怪物行为完全不变。
- **不改变世界难度、不删掉落物、不加自定义物品** —— 只是给战斗提供了一条和平的替代路径。
- 中立生物仍然遵守自己的习性（比如末影人仍会因被凝视而愤怒），模组只在「是否主动与玩家为敌」这一点上做改变。
