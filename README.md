# Peace And Love

> 让 Minecraft 的敌对生物放下武器，坐下来做生意。

一个 Minecraft Java 版模组：把原版敌对生物改造成**可交易的中立生物**。种田党和和平主义玩家无需战斗，也能用绿宝石换到怪物掉落物。

**当前状态：Alpha 预览（0.0.2）。** 中立化、仇恨与同族示警全链路已完成并通过真机自动化验证；交易系统仍在开发中。

> Alpha 为早期预览，功能与平衡可能随时变动，不代表最终品质。

---

## 这个模组做什么

原版里想要一颗末影珍珠，你得追着末影人打。装上这个模组后：

- **怪物不再主动攻击你** —— 38 种敌对生物默认转为中立
- **右键即可交易** —— 用绿宝石购买它们的掉落物
- **价格随稀有度浮动** —— 腐肉 16 绿宝石，凋灵骷髅头颅 94，僵尸掉的铁锭 117
- **每天每样限购一次** —— 游戏日刷新，不会破坏经济平衡
- **你打它，它还是会还手** —— 中立不等于无害

管理员可以通过白名单精确控制哪些生物保持原版敌对。

## 核心设计

### 双重决策门控

一个生物是否被中立化，由两个条件共同决定：

```
被中立化 = 在已适配列表中 AND 不在管理员白名单中
```

「已适配列表」是代码的能力边界（v1.0 共 38 种），「白名单」是运行时配置。这个模型让模组**天然免疫第三方 Mod 的生物** —— 它们不在已适配列表里，行为完全不受影响。

默认白名单 6 项：掠夺者、卫道士、唤魔者、恼鬼、幻翼、潜影贝。

### 仇恨机制的三条硬约束

1. **只有玩家攻击才触发** —— 铁傀儡、村民卫兵、怪物内斗、环境伤害一律不介入
2. **仇恨锁定攻击者本人** —— 玩家 A 动手，怪物只追 A，旁边的 B 不受牵连
3. **同族示警不链式扩散** —— 4 格球形内的同类被通知，但被通知者不再向外传播

玩家的投射物、TNT、宠物视同玩家攻击。脱战 30 秒或拉开 32 格后恢复中立。

### 交易实现

通过 Mixin 向 `Mob` 基类注入原版的 `Merchant` 接口，复用整套原版交易 GUI 与网络协议 —— 不自建 Menu，不写自定义数据包。

价格用对数曲线映射「每击杀期望产出」(epk)，上限 128（受 `MerchantOffer` 双输入槽限制）。110 个掉落物条目实测全部单调、无一撞顶。

## 编码前的关键验证

设计阶段做了 4 项技术验证（`docs/P1-P4-VERIFY.md`），全部基于**真实构建、真实服务端启动、字节码静态分析**，无一处推测：

| # | 验证项 | 结论 |
|---|--------|------|
| P1 | NeoForge 接口注入是否需 Access Transformer | ✅ 不需要 |
| P2 | 原版客户端能否与模组服务端交易 | ⏳ 待实测（排期 Sprint 3） |
| P3 | 注入 `Mob` 基类 vs 38 个具体类 | ✅ 维持基类，额外开销可忽略 |
| P4 | 与原版 `NeutralMob` 是否冲突 | ✅ 无冲突 |

P4 的结果推翻了原始设计假设 —— 原以为猪灵系 4 个生物已实现 `NeutralMob`，字节码全量扫描后发现实际是末影人和僵尸猪灵。这带出两个额外的特殊适配任务。

## 开发环境

```bash
# 构建双端
./gradlew build

# 启动开发服务端
./gradlew :neoforge:runServer
./gradlew :fabric:runServer
```

**注意事项：**

- Gradle 必须用 **8.10.2**（wrapper 已固定）—— Gradle 9.x 与 Architectury Loom 1.7 不兼容
- `fabric/` 和 `neoforge/` 各自的 `gradle.properties` 必须声明 `loom.platform`
- `mixin` 包内的类不能被普通代码引用，工具类要放在包外

---

## 关于 `spikes/`

前期技术验证的工作目录，包含字节码分析脚本、定价算法原型、Architectury 骨架探针。

这些是设计决策的**实证依据**（比如 110 条定价数据、`GoalSelector.removeAllGoals` 的存在性验证），因此脚本和结论 JSON 都纳入版本管理。但其中的 MC jar、mappings、Gradle 缓存共约 187 MB，已在 `.gitignore` 中排除 —— 需要时可重新下载生成。
