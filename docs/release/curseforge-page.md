# Peace And Love — 让怪物坐下来和你做生意

厌倦了被苦力怕炸掉农场、为一颗末影珍珠追着末影人满世界跑？**Peace And Love** 把原版敌对生物变成**可以交易的中立生物**——不用拔刀，用绿宝石就能买到它们的掉落物。专为热爱种田、建筑与和平玩法的玩家设计。

> ⚠️ **Beta 早期版本（0.1.0）**：核心玩法已完整可用，平衡仍在打磨，欢迎在评论区或议题区反馈。

## ✨ 特性

- 🕊️ **38 种原版敌对生物默认中立**：苦力怕、骷髅、僵尸、末影人、监守者、猪灵……不再无端攻击。
- 💎 **空手右键直接交易**：用绿宝石购买末影珍珠、骨头、火药、烈焰棒等掉落物。
- ⚖️ **稀有度定价**：常见掉落几枚绿宝石，凋灵骷髅头颅等稀有物昂贵；每样商品每个游戏日限购一次、每日补货。
- ⚔️ **中立不是无害**：你先动手，怪物就只记你的仇并反击；4 格内同族会来援，但不无限连锁。
- 🧘 **脱战恢复**：30 秒不战斗或拉开 32 格，怪物冷静回中立。
- 🛠️ **管理员白名单**：`/pal whitelist add/remove` 让指定怪物保持原版敌对，**热切换、免重启**。默认 6 种（掠夺者/卫道士/唤魔者/恼鬼/幻翼/潜影贝）保持敌对。
- 👑 **Boss 只中立、不交易**（如凋灵）；**末影龙完全不受影响**。

## ✅ 只需服务端安装

**原版客户端无需安装本模组即可加入并交易**——交易走原版村民界面与协议，非常适合和平向生存服务器。

## 📦 安装要求

- Minecraft **1.21.1** · Java **21**
- 加载器：**Fabric** 或 **NeoForge**
- 前置：**Architectury API**（Fabric 端另需 Fabric API）

## 🔎 它不做什么

- 不影响第三方模组添加的生物（仅 38 种原版适配怪）。
- 不改难度、不删掉落物、不加自定义物品，只给战斗一条和平替代路径。

模组图标为自制素材，随源码按 MIT 公开；生物贴图与界面沿用 Minecraft 原版资源。
